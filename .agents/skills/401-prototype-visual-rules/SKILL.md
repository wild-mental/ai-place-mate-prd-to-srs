# 로컬 시각 프로토타입 화면 규범

**단일 원천은 `docs/plan-docs/[Spec]Prototype-Visual-Plan.md` 다.** 이 스킬은 그 문서에서
**어기기 쉬운 것만** 뽑아 둔 것이다. 값이 필요하면 명세를 직접 읽는다.

## 범위

로컬 프로토타입 8건만 해당한다 — `INF-001` `UX-001` `INF-002` `MCK-001` `UX-003` `UX-006` `UX-004` `RNK-003`.
범위 정의는 `docs/plan-docs/prototype-suggestion-local.md`.

**전부 부분 착수다.** 명세에 없는 화면·요소·기능을 추가하지 않는다.
필요해 보이면 만들지 말고 `docs/grill/GRILL_LEDGER.md` 에 토픽으로 올린다.

## 화면은 8종이다 (명세 §1.1)

`S1` 조건 입력 · `S2` 스켈레톤 · `S3` Top-3 정상 · `S4` 90일 경고 · `S5` 후보 2건 ·
`S6` 결과 0건 · `S7` 파싱 실패 폴백 · `S8` 오류.

- **9번째 화면을 만들지 않는다.**
- 상태는 한 번에 하나만 성립한다. 경로는 명세 §1.1 표 그대로.

## 고지 배너는 상태가 아니다 (명세 §1.2)

`N1` 유사 메뉴 대체 · `N2` 반경 3km 확대 · `N3` 예산 초과 N곳 제외.

| 어기기 쉬운 것 | 규칙 |
| --- | --- |
| 배너를 독립 화면으로 만든다 | ❌ — S3·S4·S5 **위에 얹는 요소**다 |
| 하나만 뜨게 만든다 | ❌ — **N1·N2는 동시에 뜬다.** 스택으로 쌓는다 |
| 경고색·오류색을 쓴다 | ❌ — 조정 사실 고지이지 오류가 아니다 |
| N3을 상단에 둔다 | ❌ — **하단**이다. 결과의 각주다 |
| S6·S7·S8에 배너를 얹는다 | ❌ — 정상 결과가 있는 상태에만 얹힌다 |

**왜 지켜야 하는가** — 셋 다 PRD가 `표기율 100%` 를 건 항목이다(US-1 AC2 · US-2 AC2 · US-2 AC4).
시스템이 요청을 조정해 놓고 밝히지 않으면 **근거를 빼는 것**과 같다. 이 제품은 근거로 성립한다.

## 후보 카드는 슬롯 5개 · 순서 고정 (명세 §2.1)

`①` 순위·매장명·인당 예상가 범위 → `②` 선정 이유 1줄 → `③` 근거 속성 칩 →
`④` 90일 경고(조건부) → `⑤` 확인 일자 · 확인 주체.

| 어기기 쉬운 것 | 규칙 |
| --- | --- |
| 카드마다 순서를 바꾼다 | ❌ — **세 장이 같은 순서·같은 자리**여야 눈이 훑는다 |
| 인당가를 단일 값으로 쓴다 | ❌ — **범위**다 (`1.8~2.2만`). 부실하면 '가격 확인 필요' |
| 경고 없는 카드에 빈 줄을 남긴다 | ❌ — `④` 는 조건부 슬롯이다 |
| 예산 초과 매장을 카드로 그린다 | ❌ — 배너 `N3` 로 요약한다 |

## 비교표는 가로 스크롤 금지 (명세 §2.2)

축 4개 고정 — **인당가 · 대표메뉴 · 상황속성 · 확인일자**. 라벨 열 56px + 3열 등분.

- **값은 최대 5자.** 넘치면 폰트를 줄이지 말고 **값을 줄인다**
- 후보 2건(S5)이면 **2열로 줄인다.** 빈 열을 만들지 않는다

## 확인 주체는 값 4종뿐 (명세 §2.3)

`매장 등록` · `후기 코멘트` · `운영자 검증` · `자동 수집`. 표기는 `M/D · 주체`.
**다섯 번째 값을 만들지 않는다.**

## 용어 고정

| 쓴다 | 쓰지 않는다 |
| --- | --- |
| **후기 코멘트** | 이용자 확인 · 리뷰 · 별점 · 평점 |

문구·변수명·주석 전부 해당한다. '리뷰' 계열은 **v0.2로 연기한 기능**이라 혼동을 만든다.

## 항상 걸리는 것

- **빈 화면 금지** (SRS §6.3-6) — 어느 상태에서도 흰 화면을 만들지 않는다
- **판정형 문구 금지** (SRS §6.3-4) — '좋습니다' 같은 단정을 시각 언어에서도 쓰지 않는다
- **근거 4항목 없는 카드 금지** (SRS §6.3-2) — 하나라도 없으면 카드가 되지 못한다
- **shadcn/ui 자체 구현 금지** (D-08 · REQ-TEC-007) — 인벤토리에 있으면 그것을 쓴다
