## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: US-5·6의 정상 AC가 통과한다
- Given: 대화방 픽스처가 준비된 상태에서
- When: 테스트를 실행하면
- Then: 프로필 등록과 소환·정렬 AC가 통과한다. **소환 3–5곳 · 근거 표기율 100%**

Scenario 2 (실패 흐름): 근거 없는 제안이 거부된다
- Given: 등록 속성으로 뒷받침되지 않는 headline을 제출하고
- When: 테스트가 응답을 검사하면
- Then: 400이 반환되고 저장되지 않는다. **근거 없는 제안 문구 0건**

Scenario 3 (실패 흐름): 제안 0건에 빈 화면이 나오지 않는다
- Given: 180초가 지나고 유효 제안이 0건인 픽스처에서
- When: 결과를 검사하면
- Then: 제안 없는 Top-3로 복귀하고 사실이 안내된다. **빈 제안 화면 노출 0건**
