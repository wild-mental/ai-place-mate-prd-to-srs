## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 세션당 추론 비용이 집계된다
- Given: 토큰 사용량이 적재된 상태에서
- When: 일간 집계가 실행되면
- Then: 세션당 추론 비용이 산출되고 목표와 대비된다. **세션당 ≤ 12원 (REQ-NF-013)**

Scenario 2 (실패 흐름): LLM 호출 비율 상승이 조기에 드러난다
- Given: `parse_path` 의 `llm` 비율이 45%인 상태에서
- When: 일간 집계가 완료되면
- Then: 알림이 발송된다. 비용과 지연이 **동시에** 악화되는 선행 신호다. **LLM 호출 비율 일간 ≤ 40%**

Scenario 3 (실패 흐름): 단위 경제가 무너지면 보고된다
- Given: 성사 1건당 수수료가 처리 비용의 3배 미만인 상태에서
- When: 월간 리포트가 산출되면
- Then: 미달이 명시된다. 사업 모델 성립 여부에 관한 신호다. **수수료 > 처리 비용 × 3 (REQ-NF-014)**

## ⚙️ Technical & Non-Functional Constraints
- 비용: **REQ-NF-013** 세션당 ≤ 12원 · 일간 > 18원 시 알림. **REQ-NF-014** 성사당 수수료 > 처리 비용 × 3.
- 선행 지표: LLM 호출 비율은 비용·지연의 **선행 지표**다. 비용이 오른 뒤가 아니라 비율이 오를 때 대응한다.
- 운영: 제안 품질 심사는 가맹점 150곳당 1 FTE 상한. 초과 시 신규 온보딩 속도를 조절한다(LIM-09).
